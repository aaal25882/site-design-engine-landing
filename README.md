# موتور طراحی سایت

یک جمله بنویسید که سایت چه شکلی باشد؛ موتور با هوش مصنوعی رنگ‌ها، تم روشن و تیره، گوشه‌ها، فاصله‌ها و حرکت را می‌چیند — بی دست زدن به محتوا.

صفحه‌ی معرفی: https://aaal25882.github.io/site-design-engine-landing/

مدل زبانی را خود سایت میزبان صدا می‌زند؛ موتور به هیچ سرویس یا کلیدی وابسته نیست. کد این موتور خصوصی است؛ این صفحه فقط برای معرفی آن است.
