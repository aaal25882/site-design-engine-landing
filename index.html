موتور طراحی سایت

یک جمله بنویسید که سایت چه شکلی باشد؛ موتور با هوش مصنوعی رنگ‌ها، تم روشن و تیره، گوشه‌ها، فاصله‌ها و حرکت را می‌چیند — بی دست زدن به محتوا.

TypeScript · بی وابستگی · برای هر سایتی
نمونه‌ها سایت آئورا

چه می‌کند«هوش مصنوعی پیشنهاد می‌دهد، موتور می‌سنجد»

✍️

درخواست به زبان ساده

«مینیمال، سیاه و سفید، گوشه‌های تیز» کافی است؛ لازم نیست کسی CSS بلد باشد.

🌗

روشن و تیره با یک جمله

تم تیره‌ی واقعی، پیش‌فرض روشن، تیره یا هم‌رنگ دستگاه، و دکمه‌ی تعویض برای بازدیدکننده.

👁️

همیشه خوانا

رنگ نوشته‌ها خودکار به کنتراست استاندارد WCAG می‌رسد، حتی اگر پیشنهاد مدل کم‌رنگ باشد.

🛡️

فقط ظاهر، نه کد

مدل HTML یا JavaScript نمی‌نویسد؛ فقط مقدارها را انتخاب می‌کند. CSS اضافه پاک‌سازی و به خود صفحه محدود می‌شود.

🧩

برای هر سایتی

هر صفحه با یک «میزبان» وصل می‌شود: می‌گوید کدام متغیر رنگ چیست و کدام بخش سربرگ است.

↩️

ذخیره و برگشت

مشخصات طراحی ذخیره می‌شود و CSS هر بار بی پرسیدن دوباره از مدل ساخته می‌شود؛ برگشت یک‌قدمی هم دارد.

نمونه‌هادرخواست، و شکلی که از آن درمی‌آید

چطور کار می‌کنداز یک جمله تا صفحه

  1. ۱

    سایت خودش را معرفی می‌کند

    چه صفحه‌ای است، کدام متغیر رنگ زمینه است و کدام کلاس بخش‌ها، و از میان چه قالب‌ها و فونت‌هایی می‌شود انتخاب کرد.

  2. ۲

    صاحب سایت می‌نویسد چه می‌خواهد

    درخواست فقط «توصیف ظاهر» است؛ قاعده‌ها و قالب خروجی را عوض نمی‌کند.

  3. ۳

    مدل مشخصات طراحی برمی‌گرداند

    موتور هر مقدار را جدا می‌سنجد، نادرست‌ها را با طراحی فعلی جایگزین می‌کند و کنتراست را درست می‌کند.

  4. ۴

    CSS روی صفحه می‌نشیند

    زیر یک دامنه‌ی محدود، با متغیرهای خود سایت؛ اگر نپسندید، یک قدم برمی‌گردید.
